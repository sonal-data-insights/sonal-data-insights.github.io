# 📊 Sonal Vaishnav | Data Analytics Portfolio

A modern, high-performance, and responsive personal portfolio tailored for Data Analytics and Business Intelligence roles. Built with a sleek dark aesthetic, fluid kinetic animations, and direct WhatsApp & email integration.

🔗 **Live Link:** [https://sonal-data-insights.github.io/](https://sonal-data-insights.github.io/)

---

## ✨ Key Features

- **Fluid Smooth Scrolling:** Powered by the **Lenis Momentum Engine** for a seamless, continuous gliding experience.
- **Executive Typography:** Clean typographic hierarchy using **Cabinet Grotesk** and **Satoshi** fonts.
- **Dark Minimalist UI:** Frosted glassmorphism elements with subtle ambient background glows.
- **Interactive Quick Connect:** Instant action buttons for LinkedIn, GitHub, Direct Calling, and Email.
- **Direct WhatsApp Messaging:** Working contact form that pre-formats and sends client inquiries directly to WhatsApp.
- **Fully Responsive:** Pixel-perfect adaptive layout across mobile, iPad, tablets, and wide desktop screens.
